# AI Engineer Bootcamp

This repository contains my learning exercises, experiments, and projects as I prepare for an AI Engineer role.

## Project Structure

- `src/` — Reusable Python code and application logic.
- `tests/` — Automated tests for verifying code behavior.
- `data/` — Datasets and sample inputs.
- `learning/` — Learning notes, exercises, and experiments.
- `projects/` — Practical projects developed during the bootcamp.
- `requirements.txt` — Python package dependencies.
- `.gitignore` — Files and directories Git should ignore.

## How to Run

### Prerequisites

- Anaconda or Miniconda
- Visual Studio Code
- Python extension for VS Code

### Setup

Activate the Conda environment:

```bash
conda activate ai-engineer
```

### Run the Program

From the repository root, execute:

```bash
python src/hello.py
```

The program prints a greeting and demonstrates basic Python arithmetic and variable types.
